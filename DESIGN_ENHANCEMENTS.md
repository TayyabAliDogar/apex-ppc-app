## 🎨 Design System

### Color Variables (Dark Theme)
```css
--accent-primary: #00D9A3  /* Vibrant emerald */
--success: #00D9A3
--error: #FF5757
--warning: #FFB020
--info: #4DA3FF
```

### Shadows
```css
--shadow-sm: 0 2px 8px rgba(0, 0, 0, 0.4)
--shadow-md: 0 4px 16px rgba(0, 0, 0, 0.5)
--shadow-lg: 0 8px 32px rgba(0, 0, 0, 0.6)
```

### Glows
```css
--glow-primary: 0 0 20px rgba(0, 217, 163, 0.3)
--glow-accent: 0 0 30px rgba(0, 217, 163, 0.2)
```
